# CFA Partner — версии для GitHub Pages

В архиве находятся два самостоятельных статических сайта:

- `CNPC/` — актуальная версия CNPC со знаком, красно-белыми акцентами и текстом о бесплатном вводном курсе.
- `MIKI/` — сохранённая версия MIKI в исходной бирюзово-золотой стилистике.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Выберите нужную папку (`CNPC` или `MIKI`) и загрузите **её содержимое** в корень репозитория.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Укажите ветку `main`, папку `/ (root)` и нажмите `Save`.
6. Через несколько минут GitHub покажет адрес опубликованного сайта.

## Структура каждого сайта

- `index.html` — вся разметка и текст страницы.
- `styles.css` — дизайн и адаптация под мобильные устройства.
- `script.js` — работа формы и блока FAQ.
- `assets/` — логотип, фавикон и изображение для социальных сетей.

## Подключение формы

GitHub Pages не обрабатывает заявки самостоятельно. Для отправки данных можно
использовать Formspree или аналогичный сервис.

В файле `script.js` замените:

```js
const FORM_ENDPOINT = "";
```

на адрес вашей формы, например:

```js
const FORM_ENDPOINT = "https://formspree.io/f/your-form-id";
```

Перед рекламным запуском добавьте реальные контакты, политику обработки
персональных данных и подтверждённые условия партнёрской программы.
