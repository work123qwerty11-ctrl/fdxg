# CNPC CFA Partner

Готовая статическая версия для GitHub Pages.

Загрузите в корень репозитория файлы `index.html`, `styles.css`, `script.js`,
`README.md` и папку `assets`, затем включите GitHub Pages для ветки `main` и
папки `/ (root)`.

Форма подготовлена для прямой отправки заявок в Telegram. Сначала опубликуйте
защищённый обработчик из папки `../telegram-worker` по приложенной инструкции,
затем вставьте его адрес с окончанием `/submit` в константу
`TELEGRAM_ENDPOINT` в файле `script.js`.

Токен Telegram-бота храните только в секретах Worker — не добавляйте его в
файлы сайта или репозиторий GitHub.
